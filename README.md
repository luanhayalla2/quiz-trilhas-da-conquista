# Quiz Trilhas Da Conquista

14. DESENVOLVIMENTO EM ETAPAS OBRIGATÓRIAS

Não desenvolva todas as funcionalidades simultaneamente. Trabalhe em etapas e valide cada uma antes de avançar.

ETAPA 1 — Quiz básico funcional

Criar o projeto com dart create.

Implementar identificação do jogador.

Criar perguntas em listas.

Implementar alternativas A, B, C e D.

Utilizar for, stdin.readLineSync() e condicionais.

Implementar validação das respostas.

Calcular acertos, erros e pontuação.

Garantir que dart run funcione.

ETAPA 2 — Categorias

Criar as oito categorias.

Garantir pelo menos 10 perguntas exclusivas em cada categoria.

Testar todas as categorias individualmente.

ETAPA 3 — Arquitetura e testes

Separar modelos, serviços, dados e menus.

Implementar testes automatizados.

Executar dart analyze e dart test.

ETAPA 4 — Funcionalidades avançadas

Implementar os modos de jogo.

Adicionar XP, moedas, níveis e conquistas.

Implementar ranking, histórico e estatísticas.

Adicionar persistência em JSON.

ETAPA 5 — Finalização

Melhorar a identidade visual do terminal.

Criar o README completo.

Revisar a organização do projeto.

Executar novamente todos os testes.

Preparar o projeto para publicação no GitHub.

REGRA DE VALIDAÇÃO: Ao concluir cada etapa, informe os arquivos criados ou modificados, os comandos executados, os resultados reais e os problemas encontrados. Não avance se os requisitos essenciais da etapa anterior estiverem quebrados.

Não marque nenhum item do checklist como concluído sem comprovação real.
